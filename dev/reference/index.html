ScaledSArray{S, T, D, F, A <: StaticArray{S, T, D}} <: SpecialSArray{S, T, D}

Struct for lazily representing the product of a StaticArray (of type A) with a scale factor (of unrelated type F, expected to be scalar).

This can be beneficial in situations like scale matrix - vector product. For example, if s is a scalar, sm a (M, N) (static) matrix and sv a length-N vector, then s * sm * sv (i.e. (s * sm) * sv) requires M * N multiplications with s, while SMatrix(ScaledSMatrix(s, sm) * sv) delays the multiplications with s until the end in the SMatrix conversion, requiring only N multiplications. adaptive_density_control!(

    new_gaussian_counts_cs, nb_ngaussians,
    splitting_scale_factor
)

Modify mtgv in place by applying adaptive density control. To-prune Gaussians will be removed, to-clone Gaussians will be copied over twice, to-split Gaussians will for the most part also be copied over twice, but their means will be resampled and their scaling adjusted. The remaining Gaussians are simply copied over once.

Arguments

  • should_prune: Bool vector which indicates for each Gaussian if we should prune (i.e. remove) it.
  • should_densify: Similar vector, indicating whether we should densify a Gaussian. Should be mutually exclusive with should_prune, i.e. they cannot be both true at the same time. They can be both false, in which case we just carry the Gaussian over.
  • should_clone: Indicates for those Gaussians we densify, whether we should clone (true) or split (false).
  • new_gaussian_counts_cs == accumulate(+, .!should_prune .+ should_densify) where the second argument indicates how many new Gaussians an old Gaussian should spawn (0 if pruned, 2 if cloned or split (in which case we should not prune), 1 if carried over).
  • ngidx_to_gidx: A vector of indices pointing from each new Gaussian to the original one that spawned it.
  • nb_ngaussians == new_gaussian_counts_cs[end]: The total number of Gaussians after this adaptive density control step.
  • splitting_scale_factor: Training options which determines how much split Gaussians get shrunk down.

In the latter case there needs to exist a generic non-typed inner constructor taking in the fields, i.e. S(fields...) [where ...] = new{...}(fields...) (and not (only) S{...}(fields...) [where ...] = new{...}(fields...)) for both the mutable and immutable structs.

ThreeDGaussianSplatting.@im_mutable — Macro
@im_mutable [mutable_prefix immutable_prefix abstract_prefix] struct_def

A macro to create both a mutable and immutable version of a struct. We also create an abstract supertype for both. If the supplied struct expression declares a supertype, it will be the supertype of the new abstract (super)type.

Sometimes you want different inner constructors for the mutable and immutable versions, for example to avoid string interpolation in error messages inside of CUDA kernels. These different constructors can be explicitly declared using function :mutable(...) ... end and function :immutable(...) ... end, or by using the name of the mutable and immutable types. For common inner constructors the supplied struct name can be used, or alternatively function :common(...) ... end.

The use of @im_mutable cannot be preceeded by documentation. Therefore, this must be written afterwards. E.g.

@im_mutable struct S end

"Immutable version"
ImmutableS

Arguments

  • mutable_prefix: The name of the mutable version of the struct will be the supplied name prepended by the (Symbol, String, Char, etc.) mutable_prefix. Defaults to Mutable.
  • immutable_prefix: Similar, for the immutable version. Defaults to Immutable.
  • abstract_prefix: Similar, for the abstract supertype. Defaults to Abstract.
  • struct_def: The struct ... end expression to modify.
